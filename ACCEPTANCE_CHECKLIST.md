# ACCEPTANCE_CHECKLIST.md — минимальная проверка перед выдачей

Отмечай `[x]` только то, что **фактически** проверено выполненной командой/измерением или осмотром. За каждым пунктом в `reports/validation.md` должен стоять способ проверки и результат.

## Проверка источников

- [ ] Прочитан **полный** `input/cad-latch-spec(1).md`; использован раздел 12 с допущениями и раздел 13 с требованиями.
- [ ] Просмотрен PDF с изображениями, **не только** его извлечённый текст; сопоставлены боковой вид, задний вид, разметка H1/H2 и угол.
- [ ] Статусы У/И/О/Д/Р/? сохранены в параметрах либо таблице допущений.

## Инженерная геометрия

- [ ] Полная модель включает две проушины, отверстия, рожки, шейку, 3 ребра, фланец/крылышки, лопатку, тыльное углубление, зуб.
- [ ] H1=33,5 измерен **от макушки ушка до нижнего края фланца вдоль H**, без торца лопатки. Результат и система баз приведены.
- [ ] H2=16,5 измерен **вдоль F фланца**, а не по глобальному bounding box.
- [ ] H3=11,3 измерен от A до вершины ушка.
- [ ] L1=30,0 измерен от S до края лопатки вдоль P.
- [ ] Ø3,1 у обеих проушин (исправленный замер владельца 13.11.2026; Ø2,5 из ТЗ ошибочен); соосность; две толщины по 3,0; внутренний зазор 21,8.
- [ ] Ширина фланца 70; непрерывная симметричная фигурная кромка без ложного общего R27.
- [ ] Оба ориентировочных угла 110° имеют **правильный знак и правильные лучи** (раздел 10).
- [ ] Зуб не сильно загнут: основное направление параллельно P; рабочая ступенька **не выдумана как подтверждённый факт**.
- [ ] Шейка замыкает H1: итоговая длина численно записана; все рёбра действительно объединены с деталью.
- [ ] В основной выдаче ровно **одно связное твёрдое тело** (не набор независимых деталей).

## Проверка качества

- [ ] build123d/Python-скрипт выполнен на целевой машине без ошибок.
- [ ] У CAD тела положительный объём, валидная BREP-геометрия, нет пересечений/щелей; записаны методы проверки.
- [ ] `output/armrest_latch_v03.step` не пустой и при обратном импорте даёт ожидаемую твёрдую модель.
- [ ] `output/armrest_latch_v03.stl` не пустой, ориентирован правильно, замкнут/манifold по возможности проверен инструментально; единицы мм приняты и отмечены в передаче печатнику (формат STL сам единиц не хранит).
- [ ] STEP/STL сгенерированы из **той же** геометрии; записаны хотя бы габариты, объём, число тел и точность/параметры триангуляции.
- [ ] Деталь визуально сопоставлена с основными фотографиями. Если рендер невозможен — указать, что именно не проверено.
- [ ] Рабочее зацепление **не** объявлено подтверждённым без ответной части или испытания.

## Что должно лежать в результате

```text
src/                             # работающая параметрическая CAD-модель, параметры, проверки
output/armrest_latch_v03.step     # обязательный действительный CAD-файл
output/armrest_latch_v03.stl      # обязательный действительный файл для печати
output/*side*.*                  # желательно боковой вид PNG/SVG
output/*rear*.*                  # желательно тыльный вид PNG/SVG
output/*iso*.*                   # желательно изометрия PNG/SVG
reports/environment.md           # версии Python, build123d, окружения
reports/validation.md            # проверки с числами и статусами
reports/assumptions.md           # принятые приближения и неподтверждённые зоны
reports/print_handoff.md         # что отправлять печатнику, риски и что примерять
```

Если обязательные STEP/STL не создано либо проверки провалены — честно пометь **FAILED / INCOMPLETE** в отчёте, а не выдавай фиктивный успех. Функциональная посадка проверяется только прототипом/ответной деталью.
